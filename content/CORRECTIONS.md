# Corrections

Public log of every number we got wrong, kept in the repo on purpose.

A visible corrections log is an asset for a channel whose entire value is that
its figures are checkable. It is the cheapest possible signal that the other
numbers are trustworthy, and it costs nothing but ego.

## Policy

When an error is confirmed (`docs/05-compliance.md`):

1. Unlist the video within 1 hour.
2. Pinned comment stating the error and the correct figure.
3. Log it here.
4. If the error changes the verdict, re-cut and republish. Never quietly edit
   the description and pretend it didn't happen.
