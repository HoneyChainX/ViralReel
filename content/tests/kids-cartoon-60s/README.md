# kids-cartoon-60s — "Cami & Finn" platform test render

Second end-to-end platform test: a **60-second, fully programmatic 2D kids cartoon** —
the maximum-ability demonstration for a CPU-only host. Nothing in it is sourced or
generated by a model: every character, scene and motion is hand-authored vector animation.

**Story:** Cami, a bouncy little camel from the desert, discovers the sea and befriends
Finn the fish — title card, desert intro, sea reveal, splash entrance, beach-ball rally,
sunset dance, end card. (A deliberate kids-format echo of the desert→sea test reel.)

**Pipeline (all $0, all CPU):**
- Picture: Remotion 4 composition (`remotion/src/Cartoon.tsx`) — SVG characters with
  squash-and-stretch, blink cycles, spring title, 1080×1920@30, 1800 frames, rendered
  headless via the host's chromium_headless_shell.
- Voice: Kokoro TTS (platform voice profile) — 8 storybook lines, af_heart voice
  (`vo/generate_vo.py`, measured durations in `vo/manifest.json`).
- Sound: all SFX synthesized in ffmpeg (`mix_audio.sh`) — boings (sine sweeps) on the
  hops, noise-burst splash, alternating ball pops, end twinkles — plus the CC BY 3.0
  Lækjavik sea bed (licensed in ../desert-sea-15s/licenses.json), mixed to −14 LUFS.
- Captions burned in (kids watch muted too).

**Known limitations of this render** (docs/10 doctrine, honest record):
- No music score: the only local music engine (ACE-Step) needs a GPU; music generation
  is also forbidden on the flagship channel (D5) though not on this test.
- ElevenLabs (primary VO per D7) unset on this host — Kokoro is the sanctioned free path.
- "Made for kids" distribution carries COPPA constraints (no personalized ads, comments
  off); a kids format would need its own compliance checks before ever publishing.

Deliverable: `out/kids-cartoon-60s.mp4` (out/ untracked). Rebuild:
`cd remotion && npm i && npx remotion render src/index.ts Cartoon out.mp4` +
`vendor/kokoro/.venv/bin/python vo/generate_vo.py` + `bash mix_audio.sh` + mux.
